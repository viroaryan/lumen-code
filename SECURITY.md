# Security

If you find a security problem in Lumen (for example a way for a shared playlist code or a backup
file to do harm, or data leaving the phone that shouldn't), please report it privately using
GitHub's **Report a vulnerability** button on the Security tab of this repository, instead of
opening a public issue. We'll reply there.

Only download Lumen from https://lumen.arivna.com or
https://github.com/viroaryan/lumen-releases. Official APKs are signed with the key whose SHA-256
fingerprint is listed in the README.
